# gal-finder-skill

基于实际检索经验整理的 Galgame 资源查找 Skill，指导 AI 助手识别作品、搜索站点、筛选版本，并汇总下载入口、密码和备注。

**本项目不包含任何游戏资源、资源下载地址或网站链接，也不提供预设站点清单。** 实际使用时涉及的作品信息、站点、链接及密码，均由 AI 在执行任务时搜索、核对和整理得到。

## 编写来源

本项目由本人（Skwater）根据个人查找资源的经验，结合 AI 辅助整理、编写和迭代。

## 主要流程

- 同时识别作品与发现资源站，实际执行站内搜索，按反馈调整多语言名称、别名和片段。
- 默认查找电脑端完整本体，优先中文译本；其他平台仅在用户明确要求时查找。没有匹配译本时，尝试配对原文本体与翻译补丁。
- 提取同页多个有用链接，分别整理版本、提取码、解压密码和完整相关备注。
- 匹配资源的实际直链视为有效结果返回并计数，标注“未核查有效性”；网盘须通过分享基础核查。有直链时同时提供网盘，无直链时仅返回网盘。
- 以表格呈现结果，记录访问限制、未完成项及可复用的站点经验。

## 使用

让支持 Skill 的 AI 助手加载 [SKILL.md](SKILL.md)，并提供作品名称；有平台、语言或版本要求时一并说明。

```text
使用 $gal-finder 查找【作品名称】的资源。
```

执行环境需具备搜索与网页访问能力，动态页面可能需要浏览器交互。结果以当次获取的信息为准。

## 模型实测

以下为本人实测反馈，记录模型、推理设置及工具环境下的表现；测试结果同时受模型和工具影响。

| 模型 | 推理设置 | 工具环境 | 实测表现 |
| --- | --- | --- | --- |
| GPT-6 Luna | 高 | Codex 自带浏览器和网页控制 | 无法完整遵循 Skill 完成指令 |
| GPT-6.1 Terra | 高 | Codex 自带浏览器和网页控制 | 能部分遵循 Skill，返回一定结果 |
| GPT-6.1 Sol | 高 | Codex 自带浏览器和网页控制 | 能完整返回结果 |
| DeepSeek-V4.1-Flash1017 | High | web-access | 能完整返回结果 |

AI 学到的通用新路径保存到 `data/site-structures.local.md`，与基础指引配合读取，不改写版本内的参考文档。该文件首次有实际经验时创建，不随更新包发布；升级时保留本地 `data/` 目录。
