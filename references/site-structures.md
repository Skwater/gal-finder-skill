# 相似架构的检索与取链

先识别站点角色与操作结构，再核对实际协议。相同框架、主题或外观不能证明接口、字段、获取条件和密码相同；复用前检查当前域名、界面、表单和公开配置，将已确认参数写入 `search_profile`。

| 结构 | 操作路径 | 核对重点 |
| --- | --- | --- |
| 文章型资源页 | 搜索→文章→下载区→线路 | 表单字段、正文版本、隐藏区及评论／登录限制 |
| 作品与资源分层 | 作品→本体资源列表→具体资源／下载页 | 作品与资源编号、资源类型、平台及语言 |
| 动态面板／弹窗 | 提交关键词→作品→资源标签→展开链接 | 即时候选、关键词列表、展开信息与触发下载的区别 |
| 文件与作品双索引 | 作品→文件搜索或目录→版本文件 | 父路径、目录说明、平台、译文与分卷 |
| 目录型直链盘 | 配置→搜索／列表→目录→文件详情→实际地址 | API 基址、范围、分页、口令、编码与签名 |
| 自建分享盘 | 来源→分享页→提取码→内容 | 当前协议和获取条件，不跨服务套用接口 |
| 论坛／转载／合集 | 主帖→相关楼层→资源线索→来源 | 帖子时效、本体与补丁、合集内目标、片段链接的服务出处 |
| 长文资源章节 | 目录／正文资源区→版本→外链 | 资源区、动态展开及分线备注 |

## 搜索与动态页面

- 普通表单核对 action、方法和字段；即时提示选择实际作品；关键词列表先加入关键词再提交；作品编号确认来源与命名空间。
- HTML 外壳或折叠区不等于空结果。必要时只检查关联组件的公开代码和配置；动态注入脚本沿实际加载配置定位，不猜接口，不执行管理或写入操作。
- 公开 JSON 可辅助检索和取链，但元数据不能替代正确详情页；已知网页入口时继续打开并核对。聚合器异常回原站，迁移后重新确认入口。
- 提取地址时检查原页、新标签、弹窗和外链确认；按钮是否直接触发文件下载需先区分。

## 目录型直链盘

1. 确认搜索是当前目录还是全站，是否包含文件与文件夹及分页；用名称片段、语言和标点变体调整查询。
2. 命中文件夹后进入实际目录，结合完整父路径和说明选择平台、语言、版本，不能只选首个文件。陈旧索引或目录不存在只说明该路径失败，不推广为全站失效。
3. 索引未必覆盖全部附件；已匹配作品目录可查看实际列表，搜索不到补丁或说明文件不等于不存在，不扩展为整库遍历。
4. 从文件详情或下载按钮提取原始地址，保留签名、参数、时效及稳定目录／文件页面。目录、接口与文件地址分别记录；不请求文件核查直链有效性，也不将同一直链计作两种方式。
5. 阅读目录说明、公告、文件备注及说明文件名中的口令，按版本记录分卷、语言、补丁和工具要求；不套用其他目录规则。
