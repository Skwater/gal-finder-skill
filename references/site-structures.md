# 按页面结构检索与取链

本文件是随版本发布的基础指引；执行时同时读取已有的 `data/site-structures.local.md`（相对 skill 根目录）。按当前页面选择路径，同一站点可组合使用；表单、编号、接口和获取条件以实际观察为准。筛选、核查及单站结束条件见 [SKILL.md](../SKILL.md) 第 3～5 节，下表完成标志只针对当前步骤。

## 四类页面

| 识别特征 | 操作步骤 | 当前步骤的完成标志 | 未取得链接时 |
| --- | --- | --- | --- |
| **文章／帖子**：正文介绍资源，下载区位于文末、附件或相关楼层 | 搜索目标→打开正文→定位目标资源章节、附件及下载区→展开各线路→进入二级下载页或来源页 | 取得对应线路地址并整理密码、备注，或明确该线路的阻碍 | 不把侧栏推荐当正文；合集先定位目标章节。出现独立分享列表时转下一类处理 |
| **作品与分享分层**：作品页下有多个上传者、资源卡片或版本条目 | 打开作品→查看资源列表及分页→按平台、语言、版本筛选→逐个进入分享详情→展开各下载线路 | 每个相关分享及其线路均已取得、排除或记录受阻，不能只处理第一个分享者 | 作品编号与资源编号分开；停在作品介绍页或卡片列表时尚未完成，继续进入具体分享 |
| **目录／文件索引**：搜索结果是文件夹或文件，可进入路径、查看文件详情 | 确认搜索范围及分页→打开命中的实际目录→结合父路径和说明选择版本文件→进入详情提取地址 | 取得匹配文件的实际地址及稳定目录／详情页，分卷和独立整包关系已区分 | 索引命中但目录不存在只记该路径失败；附件搜不到时查看已匹配目录的实际列表，不遍历整库 |
| **网盘分享页**：显示提取码输入框、文件列表或分享状态 | 打开来源对应分享→必要时输入提取码→查看是否失效及内容能否访问 | 按正文第 4 节完成基础核查，或明确失效、登录／验证等限制 | 不把应用外壳当可访问内容，不因分享者自定文件名判错；回来源检查其他线路 |

目录／文件索引还应读取目录说明、公告、文件备注及说明文件名中的口令，记录适用版本，不套用其他目录规则。若作品索引与文件索引分开，先确认作品，再转文件搜索选择资源。

## 搜索控件与动态页面

| 页面现象 | 下一步操作 |
| --- | --- |
| 普通搜索框 | 输入关键词并提交，确认返回结果或明确的未命中提示；直接请求表单时依据观察到的 action、方法和字段，不猜参数 |
| 即时候选／关键词标签 | 即时候选选择实际作品；标签式输入先确认关键词已加入，再提交。使用编号前确认它对应作品还是资源 |
| 标签页、折叠区或弹窗 | 切换到资源区并展开各相关条目，区分仅展示链接与直接触发下载的控件；取链方式遵循正文第 4 节 |
| 搜索结果或资源列表有分页 | 处理当前目标的相关结果，翻页后确认页码或列表已变化，避免重复读取同页 |
| HTML 只有外壳、结果空白 | 先用浏览器查看渲染后状态、资源标签及筛选条件；仍缺数据时才沿页面实际加载的公开代码、配置定位接口，不猜接口或执行管理／写入操作 |
| 点击后原页未变化 | 检查新标签、弹窗、外链确认及下载状态，再决定是否重试，不反复点击同一控件 |
| 接口只返回编号、元数据或错误 | 检查对应详情页和实际取链入口；接口可辅助定位，但其 URL、编号或错误响应不直接充当资源下载地址 |

站点专属参数与有效操作步骤存入当次执行记录，不扩充 `sites.yaml`。

## 本地附加经验

- 本文不是封闭清单。未覆盖的路径可按实际页面探索；仅将本轮走通的通用步骤写入 skill 根目录下的 `data/site-structures.local.md`，不在运行时改写本文件。完成标准沿用正文，不增加直链有效性测试；未走通的推测只留执行记录。
- 附加文件首次有经验时创建，不预置空文件。按“识别特征→操作步骤→完成标志→异常分支”组织；写前重读最新内容，合并相似条目、删除重复描述，不逐次追加案例和日志。保留用户修改，无法确定的冲突留待合并。
- 附加经验不含具体站点、作品、地址、密码或站点专属参数；依据留在当次记录。与基础路径不同的做法注明适用条件，由当前页面证据选择，不将单站变化推广为通用规则。
- 附加经验仅补充检索与取链方法，不覆盖正文的筛选、核查、计数和停止边界。保存后检查引用及内容边界，回复说明更新位置；不可写时将待合并条目存入执行记录并告知路径，不声称已更新。文件不随包发布，升级时保留，不能用新包空模板覆盖。
