# 资源站索引格式

`data/sites.yaml` 只用于下次选站，创建与收录边界见正文第 7 节。根对象保留 `schema_version: 1` 和 `sites` 列表，每个站点仅用以下字段：

| 字段 | 必填 | 内容 |
| --- | --- | --- |
| `name` | 是 | 站点显示名称 |
| `home_url` | 是 | 确认提供资源的网站首页或稳定入口 |
| `cost` | 是 | `free`、`mixed`、`paid`、`unknown` |
| `login` | 是 | `not_required`、`partial`、`required`、`unknown` |
| `search_url` | 否 | 已确认可复用的站内搜索入口，不带本次作品关键词；未知则省略 |
| `access_notes` | 否 | 字符串列表，仅简短说明收费／登录的适用环节、条件或当前已登录，不追加操作日志 |

按已确认的站点根入口（主机＋实际站点路径）去重，同主机下的不同站点分别保留，不只按主机名或首段路径合并；确认迁移时更新入口。收费和登录按正文第 2 节判定，未知写 `unknown`，不把已有登录会话当作免登录依据。

不在索引增加其他字段。作品、查询词、搜索历史、资源页、网盘／直链、密码、核查时间、接口参数、友链列表及详细经验均留在当次执行记录；新发现的友链确认属于资源站后，作为独立站点录入。
